# Nida Mock API

A mock REST API that simulates Tanzania's NIDA (National Identification Authority) citizen lookup for testing and development.

**Base URL:** [https://nida-mock-api.onrender.com](https://nida-mock-api.onrender.com)

Interactive API docs at [https://nida-mock-api.onrender.com/apidocs](https://nida-mock-api.onrender.com/apidocs)
